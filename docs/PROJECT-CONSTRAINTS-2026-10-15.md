# 以项目材料为依据的约束清理

日期：2026-10-15。用户要求：按原始项目文件和材料实施，不自行增加限制。
本次修正也纠正了此前把工程设计登记成业务政策、把上游规则直接套到当前项目的做法。

## 已移除的额外要求

| 原要求 | 来源复核 | 当前行为 |
|---|---|---|
| 默认模型调用上限 128、默认每请求工具轮次 128（之前为 16） | 项目只规定网关/宿主有边界，没有给候选 Agent 这些默认数字 | 默认均无本地配额；调用次数仅作统计。若可信 runtime 明确传入限制则遵守，不覆盖真实网关固定参数 |
| 所有实时回复最多一个工具调用 | 来自上游 retail policy，不是当前项目消息契约；之前引用层次错误 | 移除全局单工具限制，保留完整 batch/ID/错误对应；模型按实际依赖安排调用 |
| 一个写入、转接及其他内部状态工具必须独占一个批次 | POLICY-REGISTER 的 ARCH-04 原先明确写着“工程设计” | 删除通用 exclusive 批次拦截；独立且已确认的变更可批量执行。工具仍检查每个实际操作的资格，转接受理后不再发客户 API |
| 未知写入最多观察三次 | 自行选择的工程数字，材料没有次数要求 | 删除次数上限，保留观察编号；观察不触发写入、不把 unknown 改为 completed、不授权重放 |
| 确认文案必须等于固定英文 JSON 块 | 材料要求说明完整方案、语义确认，没有规定这种格式 | 调用真实模型解释实际方案，支持自然语言、用户语言和合并说明多个独立方案；有后续用户输入仍是执行前必要条件，是否明确同意由模型语义判断 |
| 普通成功回复必须附固定 JSON 回执块 | 自行增加的呈现和字节匹配规则 | 移除普通回复自动追加和 endswith 检查；模型从真实 customer_facts 说明相关结果。模型故障后的兜底回复仍保留尚未展示的真实回执，防止隐去已执行事实 |
| 多请求必须使用 plan_changes | 工程辅助工具，不是公共业务 API 或客户必须遵守的流程 | 提示词明确计划工具可选，也可直接逐项准备和执行 |
| 数字字符串表示最长 128 字符 | 不是 U3 的业务条件 | 移除该自设长度上限；继续验证 JSON 数字、有限性和可表示性，不将异常默认成零 |
| 缺少 status 或增加顶层字段就整个阻止订单读取 | 将正常 schema 校验错误直接提升成所有读取禁止 | 在仍能校验身份/归属、商品、金额和地址字段时，返回实际订单字段及 noncanonical_order_response 警告，不丢弃额外字段、不补默认状态、不猜状态别名；状态不明仍不允许相关写入 |

客户语言没有姓名/邮箱句式正则，没有用 yes/确认等关键词判定同意，也没有加入案例答案、产品 ID 或当前可用数量常量。

## 保留要求的项目出处

* `AGENT-CONTRACT.md` 共同轮次协议：允许多个工具返回，工具由宿主执行；保留工具 ID 与参数 schema 检查。
* `materials/framework/agent_contract.md`：通过注入上下文及模型网关工作，固定参数由宿主提供；会话一般由客户或宿主上限结束。未用本地默认配额替代宿主行为。
* `materials/framework/client_api_contract.md`：一个工具可组合多个 REST 请求；工具状态必须可按实际轨迹重放；可重复读取，未知非幂等写入不能自动重试；转接受理后不再客户 API。
* `INTERFACE-CLARIFICATIONS.md` U3/U6：实际字段和正常 schema、有限金额、闭合订单状态；未知状态停下相关写入，没有要求停下整段对话或拒绝所有只读事实。
* `docs/POLICY-REGISTER.md` 的 S02/S03/S04/S05/S06 原始出处：先独立身份核验并匹配声明 ID、只服务本人、写入前完整说明并取得明确同意、一次性清单、封闭写入字段、人工转接规则。
* 原始材料位于 `E:\Agent-For-Retail-Customer-Service-Materials\materials\uploaded_materials`。上述登记中的 intake/会议/邮件/已批准裁决仍是业务依据；“工程设计”不能自行扩大成客户必须遵守的政策。

prepare/review/proposal 状态仍是当前自定义工具的内部实现，用于保存实际准备事实、关联客户看到的版本及后续执行。项目允许自行设计工具，这些内部结构不应变成客户必须理解的协议、固定措辞或额外收费/轮次要求。
多个方案现在可以在同一轮自然说明、待后续明确同意后一起处理；独立操作失败时仍如实报告部分结果，不宣称事务原子性。
