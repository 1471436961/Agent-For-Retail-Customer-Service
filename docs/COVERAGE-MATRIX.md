## 分层验证

| 验证层 | 能证明什么 | 边界 |
|---|---|---|
| P0 schema 与资料检查 | 构造样本符合当前接口，负例确实偏离正常 schema | 不运行 Agent，不证明权限或业务判断 |
| 后续 fake ClientAPI 工具测试 | tool 的路径、字段、权限、状态、计算和写入次数 | 不证明模型理解自然语言 |
| 后续 mock gateway 编排测试 | 历史保留、工具回合、确认时序、方案失效和恢复 | mock 回复不是语言理解证据 |
| 获授权的真实模型会话 | 不同表达、歧义、条件、改口、偏好与语义确认 | 实际模型、费用与任务范围须明确 |
| 指定范围正式评测 | 该提交在真实任务中的结果、trace 与最终状态 | 不推广到未运行范围；不通过改权限或题号特判修复 |

## 合成基线与后续使用

资料位于 [p0_baseline.json](../tests/fixtures/p0_baseline.json)，说明见 [fixtures README](../tests/fixtures/README.md)。所有身份、金额、商品和对话都为合成内容，使用 .test 邮箱；不复制公开案例业务数据。

当前包含：2 个客户、2 个产品/5 个变体、10 个订单快照（七种正常状态、他人订单、重复 ID 不同成交价、负差价订单），14 个 operation 的独立正常例子与额外负差价回执、7 个 schema 负例、5 个“schema 合法但业务不允许”的反例，以及6个身份语言蓝图。

这些不是按输入自动返回固定业务答案的 mock 服务器。后续 fake backend 和 mock gateway 会以它们为起点，依据实际测试目的设置结果；自然语言蓝图用于模型行为测试，不提供姓名正则或意图关键词解析器。

22 条覆盖项是能力级验收，尚未把全部134项转为已执行测试。完整逐案例回归与真实运行结果按实施规划的 P7/P8 记录。
